# RLC 대역통과 필터(BPF) 시뮬레이터 & S-Parameter 분석기 (v0.2.2)


PySide6 기반으로 제작된 대역통과 필터(BPF, Bandpass Filter) 회로 설계 및 S-파라미터 해석 프로그램입니다.  
시중에서 실제 판매되는 전자부품의 **표준 E-시리즈(E6, E12, E24, E96) 공칭값**과 **SPICE 서브서킷(.SUBCKT)** 모델을 지원하며, 2-Port ABCD 전송행렬 고속 해석 및 **NGSpice(Spice64)** 시뮬레이션을 실시간으로 비교 및 수행할 수 있습니다.

---

## 📸 프로그램 화면 구성 및 주요 기능

1. **상단 좌측: 인터랙티브 RLC 회로도 (`CircuitSchematicWidget`)**
   - 이미지 1의 BPF 회로 구조(직렬 인덕터 4개 + 병렬 공진부 3단)를 고해상도 벡터 그래픽으로 렌더링
   - **기본 설계값**:
     - `L1`, `L4`: **22 nH**
     - `L2`, `L3`: **27 nH**
     - `C1`, `C3`: **6.8 pF**
     - `C2`: **7.5 pF**
     - `L5`, `L7`: **100 nH**
     - `L6`: **220 nH**
   - **하단 병렬 션트 접지(GND) 결선**: 각 병렬 공진 소자(L5//C1, L6//C2, L7//C3)의 하단이 와이어로 결선되어 표준 3단 접지(GND) 심볼 및 GND 라벨로 연결
   - **시뮬레이션 방법 선택 (NGSpice)**: 회로도 우측 상단의 `[✓] NGSpice 시뮬레이션 [ON/OFF]` 버튼으로 `ngspice.exe` 시뮬레이션과 고속 ABCD 해석 엔진을 자유롭게 전환
   - 각 소자 위에 현재 설정된 값(예: `22 nH`, `6.8 pF`) 또는 SPICE 서브서킷 모델명이 실시간으로 표기

2. **상단 우측: 부품 개별 속성 편집 패널 (`ComponentPropertyPanel`)**
   - **하단 리스트 목록 UI 완전 제거**: 복잡한 전체 부품 행 목록을 없애고, 선택한 단일 부품의 정밀 설정에만 집중할 수 있도록 UI 간소화
   - **부품 빠른 선택기 (Quick Component Selector)**:
     - 회로도에서 소자를 클릭하거나, 패널 상단의 드롭다운 및 퀵 버튼(`직렬: [L1]~[L4]`, `병렬: [L5]~[C3]`)을 통해 즉시 원하는 부품으로 전환
     - **어두운 계열(다크 테마) 드롭다운 팝업 리스트**: 배경색 `#181826`과 선명한 화이트/시안 텍스트로 가독성 극대화
   - **선택 부품 개별 속성 카드 (`ActiveComponentCard`)**:
     - **RLC 소자 탭**:
       - **저항(R)**: `1% (E96)`, `5% (E24)`, `10% (E12)`, `20% (E6)`
       - **커패시터(C)**: `5% (E24)`, `10% (E12)`, `20% (E6)`
       - **인덕터(L)**: `10% (E12)`, `20% (E6)`
       - `[◀ 이전값]`, `[다음값 ▶]` 스텝 버튼 및 표준 E-시리즈 드롭다운, 직접 수치 입력 후 `[스냅]` 자동 변환
       - **부품 개별 ESR (등가 직렬 저항)** 및 **`[ ⚡ RLC 적용 ]` 컴팩트 버튼**: 저항값(ESR) 입력 스핀박스 바로 오른쪽에 소형 버튼으로 깔끔하게 배치
     - **SPICE 모델 (.SUBCKT) 탭**:
       - `.SUBCKT (모델명) (핀1) (핀2) ... .ENDS` 구조의 모델 텍스트 지원 (핀1과 핀2 자동 매핑)

3. **SPICE 넷리스트 양방향 편집기 (`_show_spice_netlist`)**
   - 상단 툴바의 **`[ SPICE 넷리스트 ]`** 버튼을 클릭하여 다이얼로그 호출
   - **넷리스트 직접 편집 및 회로 반영**: 사용자가 넷리스트 텍스트를 직접 수정하고 `[ ⚡ 회로도 및 시뮬레이션 적용 ]`을 누르면 파싱된 소자값이 회로도 및 시뮬레이션에 즉시 반영
   - **논리 및 연결성 검증**: 시뮬레이션은 Port 1(`in`)에서 Port 2(`out`)까지 연결되어야 하며, 로직 불일치 또는 구문 오류 발생 시 에러 메시지와 함께 **이전 상태로 안전 복원(롤백)**
   - **기본 템플릿 로드**: `[ 📄 기본 템플릿 로드 ]` 버튼으로 언제든지 L1~L7, C1~C3 기본 넷리스트 템플릿 호출 가능

4. **하단: S-파라미터 분석기 화면 (`NetworkAnalyzerWidget`)**
   - **결과 파형 CSV 파일 다운로드**: 상단 툴바 및 분석기 우측의 `[ 💾 결과 CSV 다운로드 ]` 버튼으로 주파수(Hz/MHz), S11~S22(dB/Mag), 해석 엔진 정보가 담긴 CSV 파일을 즉시 저장
   - **트레이스 선택 체크박스**:
     - `[✓] Tr1 : S11` (노란색)
     - `[✓] Tr2 : S12` (연두색)
     - `[✓] Tr3 : S21` (청록색)
     - `[✓] Tr4 : S22` (마젠타색)
   - **실시간 마우스 프로브 바 & 데이터 테이블**:
     - 그래프 영역에 마우스를 올리거나 클릭하면 해당 주파수에서의 Tr1~Tr4 수치를 실시간 판독
     - `[📊 결과 데이터 프로브 테이블]` 다이얼로그에서도 개별 CSV 저장 및 복사 지원
   - **X축 / Y축 크기 및 스케일(Log / Linear) 자유 조절**:
     - **X축**: `Start` (MHz), `Stop` (MHz) 및 스케일 `Linear` / `Log` 선택
     - **Y축**: `Min`, `Max` 및 포맷 `Log (dB)` / `Linear (Mag)` 선택

## 🚀 실행 방법

### 방법 1: 배치 파일 실행 (권장)
폴더 내의 `run_gui.bat` 파일을 더블 클릭합니다.

### 방법 2: 명령줄 실행
터미널 또는 PowerShell에서 다음 명령을 실행합니다:
```bash
python bpf_gui.py
```
